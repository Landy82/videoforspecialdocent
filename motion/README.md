# 부마 × 특별도슨트 30초 모션 숏폼 (v2.0)

**콘셉트: 선 하나가 몸이 되고, 몸이 역사가 된다.**
보라색(#62579F) 선 하나가 공연을 비추는 창이 되고, 그 창이 날짜·데이터·3D·글자로 변해 다시 선으로 돌아온다 (첫 프레임 = 마지막 프레임, 루프).

- 1080×1920, 60fps, 30초 = 120BPM 15마디. 실물 공연 영상만 사용 (AI 생성 없음)
- 서체 하나: Pretendard (Inter 기반 한글) / 색: 보라 #62579F · 라일락 #C9C2EE · 앰버 #F3B34C + 검정·흰색
- `index.html`: 모든 스타일을 `window.seek(t)` 안에서 시간만으로 계산 (CSS 애니메이션·타이머·프레임 간 상태 없음).
  임계감쇠 스프링·지수 이징, 빠른 이동엔 속도 방향 블러(창) / 진행 방향 늘림(글자)
- `audio.html`: Web Audio OfflineAudioContext — 박마다 킥, 장면 전환마다 히트, 24초 마지막 온마디 앞 라이저 → WAV
- `render.mjs`: Playwright로 60fps × 서브프레임 3장 캡처 → ffmpeg tmix 모션블러 → 사운드 합치기(-14 LUFS)

```
motion/build.sh <변환본 영상 폴더(px_*.mp4)> <작업 폴더> <out.mp4> [workers]
node motion/render.mjs stills <frames> <outdir>      # 박마다 1장 확인용
```
